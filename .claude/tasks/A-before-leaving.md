# 枠A: 退勤前

一行目的: 退勤前の30分で、再現条件が固まっている不具合修正やテスト追加を渡すためのテンプレートである。

## 使う場面

- いつ: 退勤30分前。
- 渡してよい仕事: 再現条件がある不具合の修正、テストの追加。
- 渡さない仕事: 仕様変更を伴うもの。仕様変更が要ると分かった時点でこのテンプレートの対象から外す。
- 戻り先: 翌朝に PR を見る。

## 依頼テンプレート

```
目的：（ここに記入）
対象範囲：（ここに記入）
完了条件：（ここに記入。テストが通ることを含める）
変更してはいけないもの：仕様変更を伴う変更はしない。CLAUDE.md の規約（main へ直接 push しない、依存を追加しない、.env・トークン・Client Secret を扱わない）に従う。（追加があればここに記入）
実行するテスト：python3 -m unittest discover -s x-mcp-oauth/tests（対象を絞る場合はここに記入）
判断が必要になったときの停止条件：下記固定文のとおり。
最後に報告してほしい項目：下記固定文のとおり。
```

## 停止条件（固定文）

仕様判断、外部サービスへのログイン、秘密情報、破壊的操作が必要になったら、迂回せずその時点で止め、状態と必要な操作を報告すること。

## 報告項目（固定文）

変更の目的、主要な差分、実行したテスト、確認してほしい判断点、元に戻す場合の範囲、未解決点。
