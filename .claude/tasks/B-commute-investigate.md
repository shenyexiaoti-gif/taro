# 枠B: 移動中（調査のみ）

一行目的: 通勤・移動の時間に、調査と切り分けだけを渡すためのテンプレートである。コード変更は一切させない。

## 使う場面

- いつ: 通勤・移動中。
- 渡してよい仕事: 調査と切り分け。
- 渡さない仕事: 実装。コード変更は行わない。これは明示の条件であり、例外を認めない。
- 戻り先: 到着後にレポートを見る。

## 依頼テンプレート

```
目的：（ここに記入）
対象範囲：（ここに記入）
完了条件：調査結果と切り分けの結論をレポートとして報告する。コードは変更しない。
変更してはいけないもの：コード変更はしない。ファイルの編集・作成・削除も行わない。調査対象の読み取りのみ。
実行するテスト：実行しない（コード変更を伴わないため）。既存のテストを読んで確認する場合はここに記入。
判断が必要になったときの停止条件：下記固定文のとおり。
最後に報告してほしい項目：下記固定文のとおり。
```

## 停止条件（固定文）

仕様判断、外部サービスへのログイン、秘密情報、破壊的操作が必要になったら、迂回せずその時点で止め、状態と必要な操作を報告すること。

## 報告項目（固定文）

変更の目的、主要な差分、実行したテスト、確認してほしい判断点、元に戻す場合の範囲、未解決点。
コード変更を行っていない場合、主要な差分は「なし」と明記する。
