# 枠C: 就寝前（一工程のみ）

一行目的: 寝る前に、機械的に正誤が判定できる一工程だけを渡すためのテンプレートである。

## 使う場面

- いつ: 寝る前。
- 渡してよい仕事: 機械的に正誤が出る一工程（例: テストの追加、構文・型の修正、既存テンプレートに沿ったファイル作成）。
- 渡さない仕事: 範囲の広い実装。
- 戻り先: 翌朝に PR とテスト結果を見る。

## 依頼テンプレート

```
目的：（ここに記入）
対象範囲：（ここに記入。1工程に絞ること）
完了条件：（ここに記入。機械的に正誤が判定できる基準にする。例: テストが全件通る）
変更してはいけないもの：範囲の広い実装はしない。対象範囲外のファイルには触れない。CLAUDE.md の規約に従う。
実行するテスト：python3 -m unittest discover -s x-mcp-oauth/tests
判断が必要になったときの停止条件：下記固定文のとおり。
最後に報告してほしい項目：下記固定文のとおり。
```

## 停止条件（固定文）

仕様判断、外部サービスへのログイン、秘密情報、破壊的操作が必要になったら、迂回せずその時点で止め、状態と必要な操作を報告すること。

## 報告項目（固定文）

変更の目的、主要な差分、実行したテスト、確認してほしい判断点、元に戻す場合の範囲、未解決点。
