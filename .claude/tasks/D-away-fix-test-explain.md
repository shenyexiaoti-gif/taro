# 枠D: 外出・出張（修正・テスト・説明の3点セット）

一行目的: 半日以上の外出・出張の間に、修正・テスト・説明の3点セットを渡すためのテンプレートである。

## 使う場面

- いつ: 半日以上の外出・出張。
- 渡してよい仕事: 修正・テスト・説明の3点セット。
- 渡さない仕事: 外部認証が要るもの（X API への実通信、承認画面が必要なフローなど）。
- 戻り先: スマホで PR を確認する。

## 依頼テンプレート

```
目的：（ここに記入）
対象範囲：（ここに記入）
完了条件：修正が完了し、テストが全件通り、変更点の説明が書かれていること。（追加条件はここに記入）
変更してはいけないもの：外部認証・実通信が要る変更はしない。.env・トークン・Client Secret を生成・コミット・出力しない。CLAUDE.md の規約に従う。
実行するテスト：python3 -m unittest discover -s x-mcp-oauth/tests
判断が必要になったときの停止条件：下記固定文のとおり。特に外部サービスへのログインが必要になった場合は必ず止める。
最後に報告してほしい項目：下記固定文のとおり。
```

## 停止条件（固定文）

仕様判断、外部サービスへのログイン、秘密情報、破壊的操作が必要になったら、迂回せずその時点で止め、状態と必要な操作を報告すること。

## 報告項目（固定文）

変更の目的、主要な差分、実行したテスト、確認してほしい判断点、元に戻す場合の範囲、未解決点。
