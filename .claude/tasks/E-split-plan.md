# 枠E: 手元作業中（分解案のみ）

一行目的: PC の前で作業中に、並列化のための分解案だけを作らせるテンプレートである。コード変更は一切させない。

## 使う場面

- いつ: PC の前で作業中。
- 渡してよい仕事: 並列化の分解案の作成だけ。
- 渡さない仕事: 同一ファイルの同時修正。コード変更は行わない。これは明示の条件であり、例外を認めない。
- 戻り先: 分解案を見て、別セッションへ振り分ける。
- 補足: 同時実行は最大2本まで。同じファイルを触る依頼は並列にしない。分解案はこの制約を満たす形で作らせる。

## 依頼テンプレート

```
目的：（ここに記入）
対象範囲：（ここに記入）
完了条件：対象の作業を、同時実行できる単位（最大2本、同じファイルを同時に触らない）に分解した案を提示すること。コードは変更しない。
変更してはいけないもの：コード変更はしない。ファイルの編集・作成・削除も行わない。分解案の作成のみ。
実行するテスト：実行しない（コード変更を伴わないため）。
判断が必要になったときの停止条件：下記固定文のとおり。
最後に報告してほしい項目：下記固定文のとおり。
```

## 停止条件（固定文）

仕様判断、外部サービスへのログイン、秘密情報、破壊的操作が必要になったら、迂回せずその時点で止め、状態と必要な操作を報告すること。

## 報告項目（固定文）

変更の目的、主要な差分、実行したテスト、確認してほしい判断点、元に戻す場合の範囲、未解決点。
コード変更を行っていない場合、主要な差分は「なし」と明記し、分解案そのものを報告に含める。
