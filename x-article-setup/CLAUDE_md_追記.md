# CLAUDE.md に足す2項目

ワークスペース直下の CLAUDE.md の末尾に、下の枠の中身をそのまま貼る。
Claude Code は毎セッション CLAUDE.md を読むので、次の会話から効く。

```markdown
## 作業ルール（導入時の事故から追加）

### 取ったものは、その場で保存する
- Web検索・X・ファイルから取得した一覧や数字、作った下書きは、次の作業に進む前にファイルへ保存する。
  保存先は、素材なら materials/_sources/、成果物なら outputs/。
- 保存したら「保存した：<パス>」と1行で報告する。保存前に会話が切れると全部消えるため。

### ネタ出しは主軸から外さない
- ネタを出す前に、materials/past_articles_index.md と skills/x_article_workflow/knowledge/ のネタ帳を必ず読む。
- 過去記事のカテゴリに無いジャンルのネタは出さない。広げたいときは、先にユーザーに確認する。
- 出したネタには、近い過去記事のタイトルを1本ずつ添える（主軸の中にあることの証明）。
```
