# 通常ポストをファイル保存にする貼り付け文（今すぐ使える案）

X通常ポストの下書きAPIが無いので、「執筆は自動、投稿だけ手で貼る」形に一旦寄せる。
これなら今日から使える。x_article_workflow の隣に置く前提の指示文。

手元のClaude Codeに、下の枠をそのまま貼る。

```text
X通常ポスト（記事ではない普通のポスト）用のスキルを新しく作って。
名前は x_post_workflow。x_article_workflow と役割は分けるが、buzz_style / buzz_voice /
hook_words / japanese_style は共通で読む。

やることは執筆だけ。投稿はしない。
1. ネタ帳（skills/x_article_workflow/knowledge/ネタ帳_<名前>.md）か、指定されたお題で本文を書く
2. 主張を含むなら、X記事と同じくWeb検索でファクト検証する
3. outputs/x_posts/ に <日付>_<連番>.md として保存する（1行目はタイトルではなく本文そのまま）
4. 保存したら、次の3行だけをチャットに表示して終わる：
   [貼り付け用]
   <保存先のファイルパス>
   本文冒頭20文字:「<冒頭20文字>」

保存したファイルは、僕がXアプリを開いて手でコピペし、下書き保存するか、その場で投稿する。
このスキルからは xurl も post_article.py も一切呼ばない。
```

## この案の利点

- 通常ポストの下書きAPIが無い問題を、そもそも避けられる
- 誤投稿・別垢投稿・規約違反のリスクが無い
- 今日、これを貼るだけで動く

## この案の弱み

- 「投稿までの全自動」ではなくなる。最後の貼り付けだけ手作業が残る
- 1日にまとめて何本も書いた場合、貼り付け作業がその分増える
