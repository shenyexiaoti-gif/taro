# post_article.py の --user を必須にする貼り付け文

--user を省いて別の垢に入った事故の再発防止。
post_article.py の本体は手元にしか無いので、手元の Claude Code に下の枠をそのまま貼って直してもらう。

```text
skills/x_article_workflow/post_article.py を直して。目的は「--user を省いて別の垢に投入する事故」を二度と起こさないこと。

1. --post（実投入）のときは --user を必須にする。--user が無ければ、何も送らずに
   「--user を指定して（例：--user <xurlのユーザー名>）」と表示して終了コード 8 で止める。
2. --check / --dry / --quota は、これまで通り --user なしでも動くようにする。
3. --user の既定値（default=）は消す。
4. 投入直前に「投入先：@<ユーザー名>」を1行表示する。
5. 修正前に、変更箇所の差分を僕に見せて。OKを出してから書き換えて。
6. 書き換えたら、--user なしの --post が終了コード 8 で止まることを、実投入せずに確かめて。

終わったら SKILL.md の投入手順に書いてあるコマンド例にも --user が付いているか確認して、無ければ足して。
```

終了コード 8 にしたのは、既存のゲート（2/3/5/6/7）と被らないようにするため。
